# Layout Tests - video_assembly_v2

Planned previews:
- Layout A: slide-first full-screen with talking-head picture-in-picture bottom-right.
- Layout B: face-first full-screen with slide panel on the left side.

Checks to perform:
- Does the viewer stay connected to the speaker?
- Are slide headlines readable?
- Does the face box or slide panel hide important content?
- Does either layout feel too much like a narrated deck?

Initial expectation:
- Layout A will maximize slide readability.
- Layout B may feel more personal and YouTube-native, but slide captions may be harder to read.


## Preview Results

Layout A - slide-first:
- Best slide readability.
- Face box stays bottom-right and does not cover headline/caption in the first 75 seconds.
- Feels more like a narrated visual deck, but clear for timing review.

Layout B - face-first:
- More personal and keeps the speaker dominant.
- Slide panel is readable enough for big headlines, but small captions are harder to read.
- First pass panel was too wide and covered the face; adjusted to a narrower left panel.

Recommendation for v2 full draft:
- Use Layout A if the main priority is visual punchline clarity.
- Use Layout B if the main priority is keeping the talking-head connection stronger.
- My recommendation: Layout A for this specific video because the slides carry fast visual jokes and need to be readable instantly.
