# Stop Scaling Chaos - v3 Review Package

This folder is for visual review before rendering another MP4. No full video was rendered in this pass.

## Files Created

- `review_contact_sheet.jpg` - one slide frame at each proposed visual start timestamp.
- `crop_layout_contact_sheet.jpg` - split-screen layout examples with slide on the left and cropped talking-head video on the right.
- `timing_decision_table.md` - cue-based timing decisions for all 24 slides.
- `crop_layout_review.md` - notes on the proposed split-screen crop and layout.
- `face_only_moments.md` - recommended sections where the edit should stay on your face.
- `sound_design_plan.md` - suggested SFX plan only; no SFX rendered.
- `assets/` - extracted still frames used to build the layout review.

## What To Review First

1. Open `review_contact_sheet.jpg` and check whether each slide appears at the right spoken idea.
2. Open `crop_layout_contact_sheet.jpg` and check whether the split-screen crop feels good.
3. Review `face_only_moments.md` to decide where slides should disappear.
4. Review `sound_design_plan.md` only after timing/layout looks right.
