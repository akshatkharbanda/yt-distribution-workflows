# QA Checklist

Use this before calling a distribution run complete.

- [ ] Selected video folder is correct.
- [ ] Requested assets are confirmed.
- [ ] Source transcript, brief, subtitles, or notes were checked.
- [ ] `distribution_package.md` exists.
- [ ] `preview.html` exists and is readable in a browser.
- [ ] `approval.json` exists and is valid JSON.
- [ ] All requested items are pending.
- [ ] No unrequested assets were generated.
- [ ] No external drafts were created.
- [ ] No sends, posts, publishes, or schedules happened.
- [ ] Key outputs were summarized in Codex chat.
