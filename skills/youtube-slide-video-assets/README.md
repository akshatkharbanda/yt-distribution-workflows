# YouTube Slide Video Assets

This folder is a local pointer for the existing slide/video workflow.

Do not replace that workflow with the distribution workflow.

Use the slide/video workflow for:

- support slides
- timing packages
- Google Slides / Google Vids
- Clipchamp assets
- MP4 exports
- visual review packages

Use `skills\youtube-distribution-draft-system` for written distribution assets, local previews, approvals, and later draft creation.
